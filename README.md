# HELL GATES — Dark Ambient Trilogy

Продакшн-библия трилогии **BULLS → CORE → FLASH**.

Референс атмосферы: [Sith Meditation — A Dark Atmospheric Ambient Journey](https://www.youtube.com/watch?v=UJ4e4XVQQcY)  
Инструментарий: dark ambient drones + брутальная 8-струнная гитара + глубокий industrial/rave удар.  
Сквозной сюжет: **врата в ад открываются → пребывание и выживание → выход победителем.**
