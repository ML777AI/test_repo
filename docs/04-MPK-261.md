# 04 — AKAI MPK-261: студия и лайв

MPK-261 — единственный контроллер и в студии, и на сцене. Клавиатура 61 клавиша, aftertouch, 16 падов × 4 банка, 8 фейдеров × 3 банка, 8 крутилок × 3 банка, 8 свитчей × 3 банка, транспорт, арпеджиатор, Note Repeat.

Питание: USB (bus power). Отдельный адаптер не обязателен, если USB-порт ноутбука держит ток. На Katana использовать **USB-A на левой панели**, не хаб без питания.

## Физическое подключение

### Студия

```
MPK-261 USB-B  →  USB-A ноутбука (MIDI)
MOTU M2 USB-C  →  USB-C/A ноутбука (звук)
Гитара TS      →  M2 Input 2 (Inst)
SM7B XLR       →  M2 Input 1 (Mic)
M2 Out L/R     →  мониторы / наушники
```

MPK **не** несёт звук гитары и вокала. Только MIDI.

### Лайв (минимализм)

```
MPK-261 USB-B  →  USB-A ноутбука
Ноут 3.5 mm    →  stereo DI  →  XLR L/R в FOH
```

MOTU M2 на сцену не берём. Подробности и покупки: [05-LIVE-RIG.md](05-LIVE-RIG.md).

## Драйвер и Windows

Отдельный драйвер MPK-261 для современной Windows обычно не нужен (class-compliant).  
Проверить: `Win + X → Device Manager → Sound, video and game controllers` — устройство видно.  
Отключить `Allow the computer to turn off this device to save power` на USB-корневых хабах, иначе в лайве MIDI пропадёт.

На MPK:

1. `Global` → Clock Source = **External**, когда работаешь с FL (Note Repeat и Arp в темпе проекта).
2. Для игры без DAW (редко) — Internal.
3. Сохранить Global.

## Пресеты на железе

`Prog Select` + пад = пресет.

- Заводской **Preset 11** у MPK2-серии — FL Studio: транспорт и пады под FPC. Использовать как старт.
- Сразу скопировать в **User Preset 1** `HELL STUDIO` и **User Preset 2** `HELL LIVE`. Заводской не затирать.

Как копировать: вызвать пресет 11 → `Edit` нужных контролов → `Preset` → Save в слот User.

### MIDI-каналы (зафиксировать)

| Блок | Канал | Зачем |
| --- | --- | --- |
| Клавиши | 1 | Дроны, аккорды, aftertouch → фильтр |
| Пады | 10 | FPC / one-shots / клипы |
| Knobs bank 1 | 1 CC 14–21 | Live FX |
| Faders bank 1 | 1 CC 1–8 | Уровни стемов |
| Switches bank 1 | 1 CC 22–29 | Mute / scene |
| Транспорт | MMC / CC по пресету FL | Студия |

Не вешать всё на канал 1 без разбора: иначе фейдер сдвинет ноту пада.

## FL Studio: включение MIDI

1. `Options → MIDI settings`.
2. Input: **MPK261** (или `MIDIIN2 (MPK261)` если виден второй порт) → **Enable**.
3. Output: тот же порт → **Enable** + **Send master sync**.
4. Sync: **MIDI Clock**.
5. Controller type: `Generic controller` (или Akai, если есть в списке). Не `MPC`.
6. `Auto detect controller` можно оставить.
7. `Remote control settings` → позже Load `.fsc` карты `HELL_STUDIO.fsc` / `HELL_LIVE.fsc`.

Проверка: `View → Piano roll` — клавиши зажигаются. FPC — пады бьют ячейки.

Если ноты есть, а крутилки молчат: это нормально до Link to controllers.

## Студийный маппинг `HELL STUDIO`

### Как линковать в FL (один жест на всю жизнь)

1. Клик по параметру в плагине (cutoff, send, gain).
2. Правый клик → `Link to controller…` **или** иконка MIDI-штекера в тулбаре (Multilink) → пошевелить нужный параметр → пошевелить крутилку/фейдер.
3. В окне Link:  
   - Channel = как на железе;  
   - CC = подхватится;  
   - `Remove conflicts` если старый линк мешает;  
   - галка `Auto map` выкл для точечных линков.
4. Сохранить: `Options → MIDI settings → Remote control → Save mapping as` → `HELL_STUDIO.fsc`.

После открытия шаблона: Load mapping, если FL не подхватил сам.

### Клавиши

- Octave: C1–C6 покрывает drone и лиды. Для суб октаву вниз кнопкой Octave.
- Aftertouch → Vital cutoff или SuperMassive Mix. Линковать aftertouch как extra controller в MIDI settings (`Add` → channel aftertouch).
- Sustain-педаль (если купишь): hold drone-аккордов. Не обязательна в студии.

### Пады — Bank A (FPC, канал 10)

Раскладка как MPC: низкий ряд слева = kick.

```
13 metal L   14 metal R   15 vocal chop  16 silence/stop
 9 hat closed 10 hat open  11 snare       12 clap/rim
 5 tom/cannon  6 perc      7 reverse      8 gate crash
 1 kick        2 kick alt  3 sub click    4 industrial door
```

Bank B: свои one-shots (двери, гидроудар, вдох).  
Bank C: вокальные чопы.  
Bank D: транспортные жесты (см. свитчи, дублировать не обязательно).

Note Repeat: держать `Note Repeat` + pad 1 = kick- tre mill. Clock External обязателен.

Full Level: для industrial one-shots, где velocity не нужна.  
16 Level: для живого хэта.

### Фейдеры Bank 1 — микшер шаблона

| Fader | Mixer |
| --- | --- |
| 1 | DRONE |
| 2 | AIR |
| 3 | GTR AMP |
| 4 | KICK |
| 5 | PERC |
| 6 | VOC DRY |
| 7 | VERB send master-ish (или FX SEND) |
| 8 | MASTER (осторожно, лучше не трогать на записи) |

Bank 2: внутренние уровни Patcher.  
Bank 3: не использовать в студии, зарезервировать под лайв-стемы.

### Крутилки Bank 1 — «руки в звуке»

| Knob | Параметр |
| --- | --- |
| 1 | Vital / Patcher Filter Cutoff |
| 2 | Filter Res |
| 3 | Distortion drive (Distructor / NAM drive) |
| 4 | SuperMassive Mix или send на VERB |
| 5 | Delay 3 feedback |
| 6 | Gross Beat wet (0 = off) |
| 7 | Vocal FX send |
| 8 | Drone chorus/detune |

Bank 2: гитарный тон (NAM bass/mid/treble/presence + 4 макроса).  
Bank 3: мастер EQ tilt / width — только на сведении, не на записи.

### Свитчи Bank 1

| Switch | Функция |
| --- | --- |
| 1 | Mute KICK |
| 2 | Mute PERC |
| 3 | Bypass Dist |
| 4 | Bypass Gross Beat |
| 5 | Metronome (клавиша C, через Keystroke — см. ниже) |
| 6 | Record (транспорт) |
| 7 | Play |
| 8 | Stop |

Транспортные кнопки MPK в пресете 11 уже шлют MMC. Если Play не двигает FL: `Options → MIDI → Enable MMC` / проверить, что Output enabled.

### Keystroke-кнопки (сильная сторона MPK)

В `Edit` на свитче: Type = **Keystroke**.

Полезные привязки FL:

- `F5` Playlist  
- `F6` Channel rack  
- `F9` Mixer  
- `F7` Piano roll  
- `Space` Play/Stop (если MMC капризничает)  
- `Ctrl+R` Record  
- `P` Draw, `C` Cut — только в студии, не в лайв-пресете

Лайв-пресет **без** keystroke на опасные клавиши (Delete, Ctrl+S можно оставить).

## Лайв-маппинг `HELL LIVE`

Отдельный `.fsc` и отдельный User Preset 2. Не смешивать со студией.

Лайв-проект играет **стемы**, не 80 плагинов. MPK управляет уровнями, фильтром и клипами.

### Фейдеры Bank 1 — стемы

| Fader | Стем |
| --- | --- |
| 1 | Drone bed |
| 2 | Air / choir |
| 3 | Guitar wall |
| 4 | Guitar FX |
| 5 | Drums |
| 6 | Vocal stem (если есть) |
| 7 | Spare / RE-Percussion live pads bus |
| 8 | Master (поставить потолок: не выше 0 dB, лучше линк на Fruity Balance до лимитера) |

### Крутилки Bank 1 — Performance Patcher

Patcher на master insert **до** лимитера, wet контролируемый.

| Knob | Макрос Patcher |
| --- | --- |
| 1 | Low-pass (закрыть мир) |
| 2 | High-pass (выйти в FLASH) |
| 3 | Drive |
| 4 | Verb send |
| 5 | Delay throw |
| 6 | Width |
| 7 | Rave gate amount |
| 8 | Kill (экспоненциальный fade в тишину) |

Aftertouch клавиш → тот же Low-pass, чтобы закрывать drone руками.

### Пады — Performance Mode

`View → Performance mode`. Клипы в Playlist в режиме Performance.

Пады шлют ноты канала 10. В клипе: `MIDI` trigger note = нота пада.

**Bank A — треки-клипы текущего сета** (пример короткого BULLS-сета):

```
13 spare           14 spare        15 BLACKOUT      16 STOP ALL
 9 Core Value       10 View Calc    11 View Calc B   12 WALKOFF light
 5 Total Damage A    6 TD B          7 TD C           8 Above (skip)
 1 Mechanics        2 Bravery       3 Glory B        4 Damage intro
```

`View Calc` на паде 10 запускает 20:05. Пад 12 — сцена света/тишины (пустой клип + Kill).

**Bank B — удар живьём** (тот же FPC, что в студии). Для `RE-Percussion`.  
**Bank C — fills / cannon / door.**  
**Bank D — аварийные:** mute drums, mute gtr, filter close, panic stop.

Note Repeat в лайве: только на Bank B, иначе запустит клип пачкой нот. На Bank A Note Repeat **выключить привычкой** или свитчем.

### Свитчи лайв

| Switch | Функция |
| --- | --- |
| 1 | Mute drums stem |
| 2 | Mute guitar stem |
| 3 | Bypass Patcher drive |
| 4 | Hold filter closed (gate to hell) |
| 5 | Launch next clip (если не с пада) |
| 6 | Panic: Stop + Kill |
| 7 | Play |
| 8 | Stop |

## Два режима работы руками

**Запись:** пресет 1, ASIO M2, buffer низкий, пишешь MIDI в piano roll, потом правишь. Не играй весь 14-минутный трек целиком, если можно: drone-аккорд 8 тактов + автоматизация крутилок.

**Лайв:** пресет 2, ASIO = **FL Studio ASIO** или **Generic Low Latency** на выход ноутбука (M2 нет). Buffer 512–1024. Wi-Fi выкл. RGB-софт Katana убить. Питание в розетке.
