# 05 — Лайв-риг: ноут + MPK-261

Склонность: минимализм. На сцену едут **MSI Katana 15 HX B14W** и **AKAI MPK-261**. Гитара, SM7B, MOTU M2 остаются в студии.

Это правильная схема для dark ambient: надёжность важнее «живого усилителя». Весь брутфорс уже в стемах. Руки на сцене делают **форму**: фильтр, ударные вставки, громкости, запуск `View Calculation`, уход.

## Что сцена обязана получить

FOH принимает **два XLR** (стерео) или один XLR (моно, хуже). Ноут отдаёт **небалансный 3.5 mm**. Без DI звукорежиссёр получит шум, землю и «звук из наушников».

Поэтому минимализм = два устройства у тебя + **одна коробка DI**, которую можно даже оставить на площадке, но купить нужно.

```
Katana headphone 3.5 mm TRS
        ↓ кабель 3.5 mm → 2× TS 1/4"
Stereo DI (или 2× mono DI)
        ↓ 2× XLR
FOH / колонки площадки
```

MPK только в USB. Звук через MPK не идёт.

## Покупки

### Купить обязательно (без этого лайв не сдаётся в FOH)

| Вещь | Зачем | Комментарий |
| --- | --- | --- |
| **Stereo DI-box** | Ноут → XLR | Radial ProD2 / Palmer PAN 04 / дешевле: 2× пассивных DI. Пассивный надёжнее активного (не нужна крона). |
| **Кабель 3.5 mm TRS → 2× 1/4" TS** | Выход ноута в DI | Короткий, 1–2 м, экранированный. Не «аукцион за 200₽». |
| **2× XLR** 5–10 м | DI → FOH | Если площадка не даёт. Иметь свои. |
| **USB-A–B кабель** запасной | MPK | 3 м, феррит. Рабочий + запас в рюкзаке. |
| **Блок питания ноута + удлинитель** | 40–70 мин сет | Katana без розетки в High Performance сядет и урежет CPU. |

### Купить сильно желательно

| Вещь | Зачем |
| --- | --- |
| **Expression-педаль** в EXP вход MPK | Нога на фильтре. Руки свободны для падов. Roland EV-5 / M-Audio EX-P. |
| **Sustain-педаль** в Sustain вход | Держать drone-аккорд на `View Calculation`. |
| **Наушники закрытые** | Свой мониторинг, если мониторов сцены нет. Не AirPods. |
| **USB-флеш / второй SSD** | Копия `HELL_LIVE.flp` + стемы + FL installer. |
| **Маленький фонарь / дуктап / стяжки** | Кабель на полу, свет пульта. |

Expression — единственная покупка, которая реально меняет шоу при схеме «только ноут+клавы». Фейдеры и knobs уже есть.

### Не покупать для лайва

- Второй аудиоинтерфейс «для сцены».
- MIDI-стойка с подсветкой на 40 кг. Достаточно лёгкой X-stand под 61 клавишу.
- Лаунчпад / второй контроллер.
- Сценический микрофон «на всякий». Вокал в базовом сете — стем.
- Гитарный процессор на пол. Гитара уже в стемах.
- Активные колонки, если играешь в клубах с FOH. Купить пару — только для домашних репетиций лайва (можно репетировать в наушниках).

### Студия, не сцена (отдельный короткий список)

Покупать только если упрёшься при записи:

| Вещь | Когда |
| --- | --- |
| **TritonAudio FetHead** | SM7B шумит при gain M2 > ~80%. Не брать Cloudlifter, если хватает FetHead. |
| Стойка + панцирная «паук»-держалка под SM7B | Если микрофон ещё на столе. |
| Поп-фильтр | Обязателен для речи вблизи. |
| Третья+четвёртая 8-струнная струна запас | Drop E рвёт. |
| Стойка под MPK | И дома, и на сцене одна. |

MOTU M2 + SM7B без FetHead часто хватает при технике 3–8 см. Сначала записать тест, потом покупать.

## Ноутбук Katana: боевая конфигурация

Игровой ноут шумный. Для ambient это риск (вентиляторы в тишине).

1. Питание в розетке. План электропитания: High Performance.
2. Выключить: Wi-Fi, Bluetooth, RGB-софт (Mystic Light и т.п.), Discord, браузер, антивирус-скан.
3. `FL Studio ASIO` или WASAPI exclusive на Headphones. Buffer 512–1024.
4. Закрыть все плагины, которых нет в лайв-проекте. Лайв-проект = Sampler/Audio clips + 1 Patcher + FPC + Limiter.
5. Freeze не нужен, если уже стемы.
6. Яркость экрана средняя. Второй монитор не брать.
7. Отключить sleep/screensaver/крышку-sleep: `lid close = do nothing` на всякий случай, крышку не закрывать.
8. Перед выходом: 15 минут прогон всего сета, включая 20:05 outro.

Шум вентиляторов: в `View Calculation` дроны громкие, FOH закроет. В тихих паузах не подносить ноут к микрофону зала. Поставить ноут на твёрдое, не на кровать кейса; воздухозаборники свободны.

## Архитектура лайв-проекта `HELL_LIVE.flp`

Не открывать студийный проект на сцене.

Каждый трек сета = набор audio-клипов в Performance Mode (stereo WAV 48k/24). Клип стартует с пада. Quantize launch: 1 bar (для ambient можно 1 beat — меньше «ждёт сетку», но риск дыр; для врат лучше 1 bar).

Стемы на трек (не больше 6):

1. drone  
2. air  
3. guitar  
4. drums  
5. vocal (если есть)  
6. spare FX

Плюс глобальные: FPC live drums, Patcher FX, `View Calculation` как один длинный клип (можно 2 стема: bed + percussion windows).

Лимитер на master: потолок −0.5 dBTP. FOH крутит свой уровень. Ты не должен клиппить выход ноута: Windows volume **100%**, уровень крутить фейдером 8 и в Windows «не 50%». Калибровка: дома в DI, пики по SPAN не выше −6 dBFS на выходе.

## Поведение на сцене

1. Выход: Mechanics / Unity — сразу звук, не «проверка-раз-два» в зал.
2. Rave-окна: пады Bank B + Note Repeat. Тело не прыгает в EDM-эстетике; удар тяжёлый, стойка неподвижная или медленный шаг.
3. `Total Damage` / `Mind's Storm` — фильтр expression закрывается и открывается как врата.
4. За 60–90 сек до конца последнего «игрового» трека — руки с падов, свет просит down.
5. Пад **View Calculation**. Уходишь. Треку дают доиграть. Не кланяться под drone.

## Репетиция без клуба

Дома: тот же кабель 3.5 mm в DI (или сразу в мониторы, но хотя бы раз прогнать через DI).  
Слушать в тех же наушниках, что на сцене.  
Прогон: полный короткий сет + 20:05 без перерыва. Если ноут задохнулся — резать плагины, не «оптимизировать Windows красиво».

## Рюкзак на выход (минимум)

- Ноут + питание + удлинитель  
- MPK-261 + USB основной + USB запас  
- DI + 3.5 mm кабель + 2 XLR  
- Наушники  
- Флеш с копией проекта  
- Стойка (или площадка даёт клавишную стойку — уточнить)  
- Expression/sustain если куплены  
- Вода, тряпка, дуктап
