# 06 — Визуал и YouTube

Квота снятых роликов **с артистом в кадре**:

| Альбом | Роликов | Смысл |
| --- | --- | --- |
| BULLS | 2 | Ворота и трансформация |
| CORE | 2 | Отпечаток и уход (outro) |
| FLASH | 3 | Шторм, цена, ясный выход |

Полный альбом-визуализатор (обложка + медленное видео без лица или с силуэтом) **не входит** в квоту. Он нужен каждому релизу как «длинный ролик для фона», как у референса Sith Meditation.

## Визуальный закон трилогии

Одна сетка, три температуры.

| | BULLS | CORE | FLASH |
| --- | --- | --- | --- |
| Цвет | Чёрный, ржавчина, кровь-металл | Пепел, кость, глухой бордо | Выжженное золото, белый afterimage |
| Форма | Щель, створки, шестерня, бык как знак (не логотип-мультяшка) | Печать, отпечаток ладони/грифа, тоннель | Вспышка, горизонт, открытая дверь |
| Шрифт | Один гротеск на всё. Вес Bold для названия альбома, Regular для треков. Без готики Comic-Satan. | | |
| Фото | Артист в кадре редкий, крупный, прямой взгляд | Артист почти объект пространства | Артист уходит, но остаётся человеком |

Не использовать чужие IP (Sith, световые мечи, чужие шрифты кино). Референс — плотность тьмы, не косплей.

Обложки: **3000×3000 px**, квадрат, без мелкого текста (названия треков на обложку не лезут). Название альбома читается с иконки Spotify.

Серия обложек — три вариации **одного кадра-конструкции** (врата): BULLS закрыты/щель, CORE внутри, FLASH распахнуты и выжжены.

## Что снимать: привязка к трекам

Снимать **ситуации по имени трека**, не «клип с склейкой всего альбома».

### BULLS — 2 ролика

**Ролик A — Bravery & Glory (7:36)**  
Ситуация: порог. Артист стоит перед тем, во что страшно войти.  
Локации: заводская дверь, бетонная рампа, ангар, подземный паркинг, железнодорожные ворота.  
Камера: штатив, 2–3 оси, длинные планы. Почти не резать под бит.  
Костюм: то, в чём потом выйдешь на сцену. Повторяемость важнее «образа на один клип».  
Свет: один жёсткий источник сбоку + дым/пыль в щели.

**Ролик B — Total Damage Transformation (14:04)**  
Ситуация: проход и слом. Не CGI.  
Приём: один кадр «до» (собран, прямо), один «после» (пыль, мокрые волосы, другая оптика, камера ближе). Середина — движение сквозь коридор.  
14 минут на YouTube: не пытаться заполнить экшен. Ambient-клип = 80% почти статики. Можно зациклить 4–5 планов.

Не снимать отдельные клипы на Mechanics Set, Above Weakness, Core Value. Их кадры — только B-roll в визуализатор альбома.

### CORE — 2 ролика

**Ролик A — Spirit Imprint (6:33)**  
Ситуация: неподвижность внутри. Артист как отпечаток.  
Локация: тоннель, пустой бассейн, нефункционирующая церковь, шахта, бетонный бункер.  
Камера: очень медленный dolly/zoom. Одно лицо, почти без моргания. Вокал — если поёшь, снимай playback под сухой стек, губы читаются.

**Ролик B — View Calculation (20:05)**  
Ситуация: **уход**. Это документ лайва, даже если снят в репетичке.  
Схема: широкий план сцены/комнаты. Артист запускает outro и уходит из кадра в первую минуту. Камера **не** идёт за ним. 19 минут пустого пространства под трек — это и есть клип. Можно 2–3 смены угла за всё время, не больше.  
Этот ролик объясняет зрителю, зачем 20 минут outro на концертах.

Dematerialization, World's Acknowledge, Self Stages — не клипы.

### FLASH — 3 ролика

**Ролик A — Mind's Storm (7:42)**  
Ситуация: движение наружу. Handheld, ветер, пар, ночь, ходьба. Единственный «быстрый» клип трилогии. Всё равно не клип-рок: резка реже, чем в обычном рок-видео.

**Ролик B — Septic Condition (6:56)**  
Ситуация: цена. Клинический свет, портрет, близко. Почти без локации. Это человеческий ролик, чтобы трилогия не стала только архитектурой.

**Ролик C — Clear Perception (12:55)**  
Ситуация: выход победителем. Дверь на рассвет / пустая дорога / сцена после зала. Камера держит артиста, пока он не станет маленьким. В отличие от View Calculation, мы **смотрим на него**, не на пустую сцену.

Unity Equiped и RE-Percussion — B-roll (руки на падах MPK для RE-Percussion — полезно в визуализатор FLASH).

## Техника съёмки (без киногруппы)

- Телефон 4K 24 fps + штатив уже достаточно, если свет один и грамотный.
- Отдельный рекордер не обязателен: в клипах звук = мастер из FL, не с камеры. Камера пишет только картинку. Хлопушка/хлопок для синхрона.
- Стабилизация: штатив > gimbal. Gimbal только для Mind's Storm.
- Не снимать «в темноте на ISO 6400». Темнота = недоэкспонированный шум. Снимать так, чтобы чёрный был чёрным, а лицо читалось.
- Один осветитель: LED-панель или даже рабочая лампа + флаг из картона.

Максимум два сетап-дня на альбом (BULLS/CORE) и три на FLASH — по числу роликов. Не размазывать.

## YouTube-архитектура канала

Не мешать клипы, альбомы и лайв в одну кашу без плейлистов.

**Плейлисты:** `BULLS` / `CORE` / `FLASH` / `LIVE` / `VISUALIZERS`.

На каждый альбом:

1. Visualizer 37–47 мин — загрузить **в день дистрибуции**, когда треки уже на Spotify/YT Music.  
2. Артист-ролики — по одному, не все в один день. Первый ролик за 7–10 дней до релиза как сингл-видео (звук = тот же мастер, что уйдёт в DistroKid).  
3. Shorts: только из уже снятого. Не отдельная съёмка. 15–20 сек щели врат / ухода / вспышки.

Превью: квадратная обложка + крупное слово альбома. Без «RED CIRCLE» и чужих ютуб-кликбейтов. Для 20-минутного outro превью — пустая сцена.

Описание шаблон:

```
Artist — Track (Album)
Album: BULLS | CORE | FLASH
Listen: [Spotify] [Bandcamp] [Apple]
Live outro: View Calculation
```

Не ставить в описание чужой референс как «inspired by Sith» — лишний копирайт-шум.

## Синглы vs альбом на YouTube

Чтобы клип не конфликтовал с релизом:

- Залить **тот же WAV**, что в DistroKid.
- После включения Content ID — **allowlist** своих клипов и визуализаторов (иначе DistroKid заклэймит твоё же видео).
- Visualizer полного альбома: либо ждать 24–48 ч после стора, либо сразу и allowlist.

## Свет и сцена под видео (и под лайв)

Один прибор в зал: холодный белый сбоку + дым-машина площадки, если есть. Не RGB-дискотека. Для FLASH можно один тёплый луч в конце `Clear Perception`, затем тьма на `View Calculation`.
