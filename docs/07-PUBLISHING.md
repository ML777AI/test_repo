# 07 — Паблишинг

Три отдельных релиза. Три UPC. Пятнадцать ISRC. Одно имя артиста на всех.

## Куда что

| Канал | Зачем | Когда |
| --- | --- | --- |
| **DistroKid** (или аналог) | Spotify, Apple, YT Music, Deezer | Основной стор |
| **Bandcamp** | Прямые деньги, WAV/FLAC, лояльные | В день стора или на день раньше для подписчиков |
| **YouTube канал** | Клипы, визуализаторы, лайв | По плану [06](06-VISUALS-YOUTUBE.md) |
| **YouTube Content ID** | Чужие видео с твоей музыкой | Opt-in осторожно |

Не дублировать Content ID через два дистрибьютора.

## Метаданные (зафиксировать до первого аплоада)

- Artist name (одинаково везде, включая регистр)
- Album titles: `BULLS` / `CORE` / `FLASH`
- Track titles — как в этом документе, включая `Unity Equiped` и `RE-Percussion`
- Genre: **Electronic / Ambient** (не Metal, даже если гитара брутальная: сторы так лучше кладут dark ambient)
- Secondary: Industrial / Drone
- Language вокала: фактический
- Explicit: если мат — да
- Record year, ℗ ©: твоё имя / импринт
- Credits: writer, producer, mix, master — ты, если так и есть

Обложка 3000×3000, без логотипов сторов, без URL.

## Аудио для сторов

- WAV 24 bit / 48 kHz (DistroKid принимает; если попросят 44.1 — ресемпл из 48k мастера, не наоборот)
- True Peak ≤ −1.0 dB
- LUFS: **−9…−8** интегрировано для этой эстетики. −14 сделает удар игрушечным. Spotify само нормализует; лучше громкий осмысленный мастер, чем тихий «под LUFS-моду».
- Не лимитировать в кашу: запас под kick.

Имя файлов: `01_Mechanics_Set.wav` …

## Content ID и свои клипы

DistroKid Social Media Pack / Content ID:

- Можно включать, **если** все звуки свои (синтез, своя гитара, свой вокал, свои one-shots).  
- **Нельзя**, если в треке сток из FL / Splice / «cinematic boom».
- После включения: allowlist всех своих YouTube URL (клипы, визуализаторы, лайв-съёмки).
- Не разрешать чужие ремиксы, если ID включён — будет путаница клеймов.

Если в BULLS всё же попал чужой one-shot — Content ID на этот альбом не включать. На CORE/FLASH включить, если чисто.

## Порядок выкладки одного альбома

1. Мастера + обложка + метаданные готовы.  
2. DistroKid upload, дата стора = T. Заливать с запасом на модерацию.  
3. Bandcamp: пресейв/публикация в T минус несколько часов для своих.  
4. YouTube: артист-ролик №1 как «сингл» до T (звук = мастер будущего альбомного трека).  
5. День T: сторы + визуализатор полного альбома + ссылки везде.  
6. После T: артист-ролик №2 (и №3 для FLASH).  
7. Лайв: уже играется, outro = View Calculation.

Не выпускать все синглы альбома по одному на стриминг — для ambient это дробит прослушивание. Один сингл-видео на YouTube + сразу полный альбом в сторах.

## BULLS → CORE → FLASH

- BULLS выходит первым, даже если CORE наполовину написан.  
- Между альбомами: лайвы, ролик outro, допись следующего.  
- FLASH не анонсировать вместе с BULLS. Миф держится на том, что выход ещё не случился.  
- На Bandcamp сделать **discography bundle** только после FLASH.

## Юридическое минимум

- Не сэмплировать референс с YouTube.  
- Контракт с площадкой съёмки, если это частный завод.  
- Соседи по сплиту нет — 100% master + 100% composition на тебя, пока не появится соавтор.  
- Тексты сохранить в `.txt` рядом с проектом (для Content ID disputes и буклета).

## Канал и «как у референса»

Референс живёт как **4-часовой фон**. У тебя три альбома конечной длины — это сильнее как высказывание. Визуализатор альбома закрывает запрос «поставить и работать/медитировать». Клипы с лицом закрывают запрос «кто это». Лайв-outro закрывает запрос «что за ритуал».

Не гнаться за 4 часами. 38 / 47 / 37 минут — правильный размер пластинки.
