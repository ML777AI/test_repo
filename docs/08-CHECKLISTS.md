# 08 — Чеклисты

## A. Разово, до первой ноты

- [ ] Имя артиста зафиксировано
- [ ] Папка `D:\HELL\` создана
- [ ] VST3-папка одна, плагины просканированы
- [ ] Vital, Surge XT, SuperMassive, NAM, SPAN, Nova, Youlean стоят
- [ ] MOTU M2 = 48 kHz, драйвер ASIO
- [ ] SM7B тест: речь −12 dBFS без дикого шума
- [ ] Гитара в Drop E (или выбранный строй), запас струн
- [ ] `HELL_TEMPLATE.flp` сохранён
- [ ] MPK User Preset 1 STUDIO, User Preset 2 LIVE
- [ ] `.fsc` карты сохранены в `_template`
- [ ] Куплены: stereo DI, кабель 3.5→2×TS, запасной USB, XLR
- [ ] Expression-педаль — да/нет (решение)

## B. На каждый трек

- [ ] Хронометраж в допуске
- [ ] Drone ложе не дырявое (SPAN: энергия 30–80 Hz есть)
- [ ] Kick не съел drone (sidechain короткий или его нет)
- [ ] Есть хотя бы одна пауза/дыра
- [ ] Сухие стволы: DI гитары, вокал, MIDI
- [ ] Нет стоковых лупов, если нужен Content ID
- [ ] Черновой слушательский прогон в наушниках и на телефонах
- [ ] Название файла и теги совпадают с карточкой альбома

## C. Перед мастером альбома

- [ ] Все 5 треков в одной громкостной семье
- [ ] Паузы между треками осознанные (0.5–2 с, не 0)
- [ ] True Peak ≤ −1 dB
- [ ] Обложка 3000×3000
- [ ] Тексты сложены
- [ ] ISRC после аплоада DistroKid сохранить в таблицу

## D. BULLS готов к релизу только если

- [ ] 5 мастеров
- [ ] Обложка BULLS
- [ ] 2 артист-ролика сняты и сведены по картинке
- [ ] Визуализатор 37:53
- [ ] **Черновик View Calculation 20:05 лежит в HELL_LIVE**
- [ ] Короткий лайв-сет прогнан целиком дома
- [ ] DistroKid форма заполнена, Bandcamp страница есть
- [ ] Allowlist план для своих URL

## E. Лайв, день выхода

- [ ] Розетка, питание, крышка sleep = never
- [ ] Wi-Fi выкл, RGB выкл
- [ ] `HELL_LIVE.flp` открыт, ASIO на наушники/выход
- [ ] MPK Preset 2, Clock External
- [ ] Пад 10 = View Calculation, проверка
- [ ] DI, земля, звук в FOH не клиппит
- [ ] Запасной USB в кармане
- [ ] Флеш-копия проекта
- [ ] После сета: не выдёргивать USB на Play

## F. CORE / FLASH дополнительно

- [ ] CORE: финальный View Calculation заменил черновик в лайв-сете
- [ ] CORE: ролик ухода снят
- [ ] FLASH: 3 ролика, последний — выход с человеком в кадре
- [ ] FLASH: Bandcamp bundle трилогии
- [ ] Нигде не выложен «полный 15-track LP» вместо трёх альбомов
